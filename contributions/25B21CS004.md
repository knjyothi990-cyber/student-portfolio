\## Three Git Commands

1\. git init - Initializes a new Git repository.

2\. git add . - Stages files for committing.

3\. git commit -m "message" - Saves changes.



\## Purpose of GitHub

GitHub is used to store, manage, and share

code online. It helps developers collaborate.



\## Benefit of Branches

Branches allow developers to work on changes

without affecting the main branch.
